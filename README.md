# Boiler monitor

Автоматика для бойлера на розумній розетці Tuya. Керується станом мережі
та акумулятора з інвертора Deye. Сповіщення й кнопки — в Telegram.

## Як працює

Скрипт запускається кожні 5 хвилин (GitHub Actions). Кожен запуск:

1. читає з Deye Cloud напругу мережі, заряд і температуру АКБ, струм заряду;
2. читає з Tuya Cloud стан розетки бойлера;
3. перевіряє, чи натискали кнопки в Telegram;
4. діє за правилами нижче.

Стан між запусками зберігається у `state.json`.

## Правила

**Світло зникло** → бойлер вимкнути. Якщо був режим 40 А — повернути 80 А.
Повідомлення 🔴.

**Світло повернулось** → за замовчуванням:

| Стан АКБ | Дія |
|---|---|
| BMS обмежує заряд (холодна) або SOC ≥ 90 % | бойлер **увімкнути** |
| інакше (заряд піде на повну) | бойлер **вимкнений**, чекати |

Повідомлення 🟢 з кнопками.

**Кнопки** (працюють будь-коли, поки є світло, спрацьовують на наступному запуску):

- 🔋 **40 А + бойлер** — обмежити заряд і увімкнути бойлер
- ⚡ **80 А, бойлер OFF** — повний заряд, бойлер вимкнути

**Автоматика між натисканнями:**

- бойлер вимкнений, SOC дійшов до 90 % → увімкнути бойлер, повідомлення з кнопками
- режим 40 А, споживання з мережі < 2.5 кВт → повернути 80 А, повідомлення з кнопками
- натиснув ⚡ при SOC ≥ 90 % → бойлер вимкнено свідомо, сам не вмикається до наступного відключення

**Ручне керування поважається:** між подіями скрипт розетку не чіпає.
Якщо бойлер увімкнули вручну під час відключення — одне нагадування ⚠️.

## Повідомлення

```
🟢 Світло повернулось
Мережа: 2.3 кВт | Будинок: 0.3 кВт
АКБ: 75% (заряд 1.8 кВт), 9 °C
Заряд: 80 А
Бойлер вимкнено. Увімкну сам при АКБ ≥ 90%.
[🔋 40 А + бойлер]  [⚡ 80 А, бойлер OFF]
```

## Налаштування

У `.github/workflows/boiler.yml`:

| Параметр | Значення | Що означає |
|---|---|---|
| `VOLTAGE_THRESHOLD` | 100 | напруга, нижче якої мережі "нема", В |
| `GRID_POWER_MAX_KW` | 2.5 | поріг повернення 40 → 80 А, кВт |
| `CHARGE_A_NORMAL` | 80 | звичайний струм заряду, А |
| `CHARGE_A_ECO` | 40 | знижений струм заряду, А |
| `SOC_BOILER_OK` | 90 | SOC, від якого бойлер вмикається сам, % |

Секрети (ключі Deye, Tuya, Telegram) — у GitHub Secrets.
